# astrbot_plugin_subconscious

AstrBot 主动私聊插件。定时调用 LLM，结合目标用户近期对话与沉默时间，决定发送简短消息或返回 `SKIP`。

## 功能

- 定时心跳评估，默认约每 60 分钟一次，带少量随机抖动。
- 评估使用单次独立 LLM 请求，不把评估提示词和思考过程追加到主会话。
- 默认北京时间 00:00–07:00 不进行常规评估。
- 支持每日发送上限、最小发送间隔、最小沉默时间和连续未回复次数限制。
- 收到目标用户私聊后记录平台与会话；成功发送的消息会追加到主会话历史。

## 安装与配置

在 AstrBot 插件管理中通过仓库地址安装：

https://github.com/zzz27578/astrbot_plugin_subconscious

支持 AstrBot `>=4.16,<5`，并需要已配置可用的聊天模型和支持主动发送消息的平台。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `target_user_id` | 空 | 目标用户 ID，必填。留空时不启动后台主动消息任务 |
| `target_platform` | 空 | 平台实例标识，可自动识别，也可手动指定 |
| `persona_prompt` | 空 | 可选表达风格；留空使用自然、简洁、友好的表达 |
| `tick_interval_minutes` | 60 | 评估间隔，单位分钟 |
| `max_daily_proactive` | 0 | 单日最大发送次数；0 表示不限次数 |
| `min_interval_hours` | 2.0 | 两次发送的最小间隔，单位小时 |
| `min_silence_hours` | 1.5 | 目标用户未发言多久后才允许评估，单位小时 |
| `max_unanswered_pings` | 3 | 用户未回复时最多连续主动发送的消息数 |

填写配置并重载插件，然后让目标用户向机器人发送私聊，以便识别会话。计数与会话识别状态保存在内存中，重载后会重置。

## 测试指令

仅已配置的目标用户可使用：

- `/潜意识测试`：立即执行一次评估。
- `/潜意识测试 3`：模拟已沉默 3 小时进行评估。
- `/潜意识测试 force`：跳过沉默判定并生成主动消息。

测试指令会跳过常规时间与频率限制；模型生成有效内容时会实际发送私聊。

## 数据说明

代码不包含预设私人账号、昵称、专属平台名或个人化身份设定。目标用户 ID 和自定义表达风格只应在自己的 AstrBot 实例中填写。

运行时，最近四条对话（每条最多 120 个字符）和时间信息会发送给所配置的 LLM 服务，用于评估是否发送消息。
